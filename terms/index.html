# 8789 Content Studio 이용약관

최종 검토일: 2026-09-29

8789 Content Studio는 운영자가 본인의 소셜 미디어 계정을 관리하기 위해 자체 PC에서 실행하는 도구입니다. 문의 연락처는 arteolux@gmail.com입니다.

## 계정 연결 및 게시

소셜 계정 연결은 각 플랫폼의 공식 OAuth 동의 화면을 거칩니다. 운영자는 연결할 계정과 요청 권한을 확인하고 동의할 수 있습니다. 계정 비밀번호를 8789에 입력하거나 저장하지 않습니다. 게시·댓글·성과 조회 등은 해당 플랫폼에서 허용하고 운영자가 동의한 범위에서만 작동합니다. 플랫폼의 이용약관, API 정책 및 저작권 규칙을 지켜야 합니다.

## 서비스 제공 범위

영상·문안 초안 및 예약 기능은 로컬 설치 상태와 연결된 외부 서비스에 따라 달라집니다. 플랫폼 승인이 필요한 기능은 승인 전까지 사용할 수 없으며, API 장애나 권한 만료 시 작업이 중단될 수 있습니다. 본인 계정으로 테스트한 결과를 타인 계정에 대한 접근 권한으로 간주하지 않습니다.

## 해지와 삭제

운영자는 8789의 SNS 연결 화면에서 연결을 끊고 로컬 저장 토큰을 삭제할 수 있습니다. 세부 절차는 `/data-deletion`에 있습니다. 플랫폼에 이미 발행된 게시물은 해당 플랫폼에서 별도로 삭제해야 합니다.

## 공개 TikTok 공유 기능

`/tiktok/` 공개 도구는 TikTok 사용자가 본인 계정으로 로그인하고 권한을 승인한 뒤 직접 선택한 영상 파일을 TikTok 편집함에 업로드하도록 제공합니다. 사용자는 자신이 공유 권한을 가진 콘텐츠만 업로드해야 하며, 최종 편집·게시 여부는 TikTok에서 직접 결정합니다. 운영자는 서버 가동 시간, TikTok API 상태, 플랫폼 심사 결과에 따라 이 기능을 일시 중단할 수 있습니다. 이 도구는 아직 TikTok의 승인된 공개 게시 기능이라고 표시하지 않습니다.

## YouTube 채널 연결 및 영상 업로드

YouTube 기능을 이용하는 사용자는 [YouTube 서비스 약관](https://www.youtube.com/t/terms) 및 [YouTube 커뮤니티 가이드](https://www.youtube.com/howyoutubeworks/policies/community-guidelines/)를 준수해야 합니다. 업로드 전에 사용자는 영상과 포함된 음악·이미지 등의 이용 권한이 있으며 콘텐츠가 커뮤니티 가이드에 부합함을 확인해야 합니다. 사용자가 제목·설명·공개 범위를 선택하고 업로드 또는 예약을 실행합니다. YouTube는 API 프로젝트의 검증 상태에 따라 업로드 영상을 비공개로 제한할 수 있습니다. 계정 연결을 해제하면 8789에 저장된 연결 토큰을 삭제할 수 있으며, 이미 업로드한 영상은 YouTube에서 별도로 관리해야 합니다.
