# 8789 Content Studio 이용약관

최종 검토일: 2026-09-28

8789 Content Studio는 운영자가 본인의 소셜 미디어 계정을 관리하기 위해 자체 PC에서 실행하는 도구입니다. 문의 연락처는 arteolux@gmail.com입니다.

## 계정 연결 및 게시

소셜 계정 연결은 각 플랫폼의 공식 OAuth 동의 화면을 거칩니다. 운영자는 연결할 계정과 요청 권한을 확인하고 동의할 수 있습니다. 계정 비밀번호를 8789에 입력하거나 저장하지 않습니다. 게시·댓글·성과 조회 등은 해당 플랫폼에서 허용하고 운영자가 동의한 범위에서만 작동합니다. 플랫폼의 이용약관, API 정책 및 저작권 규칙을 지켜야 합니다.

## 서비스 제공 범위

영상·문안 초안 및 예약 기능은 로컬 설치 상태와 연결된 외부 서비스에 따라 달라집니다. 플랫폼 승인이 필요한 기능은 승인 전까지 사용할 수 없으며, API 장애나 권한 만료 시 작업이 중단될 수 있습니다. 본인 계정으로 테스트한 결과를 타인 계정에 대한 접근 권한으로 간주하지 않습니다.

## 해지와 삭제

운영자는 8789의 SNS 연결 화면에서 연결을 끊고 로컬 저장 토큰을 삭제할 수 있습니다. 세부 절차는 `/data-deletion`에 있습니다. 플랫폼에 이미 발행된 게시물은 해당 플랫폼에서 별도로 삭제해야 합니다.
