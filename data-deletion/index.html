# 8789 Content Studio 데이터 삭제 안내

최종 검토일: 2026-09-28

8789는 운영자의 PC에 연결 토큰과 콘텐츠 작업 데이터를 저장합니다. 외부 플랫폼의 계정 비밀번호는 저장하지 않습니다.

## 연결 토큰 삭제

1. 운영자 PC에서 `http://127.0.0.1:8789/#connection-guide`를 엽니다.
2. 연결된 SNS 계정 카드에서 **해제**를 선택합니다. Threads 계정은 `계정 연결` 화면의 연결 해제 기능을 사용합니다.
3. 연결이 사라졌는지 새로고침하여 확인합니다. 이 작업은 8789의 로컬 저장 토큰을 삭제합니다.
4. 해당 SNS의 앱 연결 관리 화면에서도 8789의 접근 권한을 취소할 수 있습니다.

## 로컬 작업 데이터 삭제

초안·발행 기록·분석 사본 등은 운영자 PC의 8789 데이터 디렉터리에 남을 수 있습니다. 백업이 필요하면 먼저 보관하고, 그 다음 운영자 PC에서 로컬 데이터 파일을 삭제합니다. 현재 제품에는 모든 로컬 작업 데이터를 한 번에 삭제하는 버튼이 없으므로 파일 삭제는 운영자가 직접 해야 합니다. 삭제 전에 앱을 종료하고, 원본 영상·이미지와 다른 프로젝트의 데이터가 섞여 있지 않은지 확인하십시오.

## 플랫폼에 이미 게시한 콘텐츠

8789에서 연결을 끊거나 로컬 파일을 삭제해도 SNS 플랫폼에 이미 게시된 콘텐츠는 자동 삭제되지 않습니다. 각 플랫폼의 게시물 관리 화면에서 별도로 삭제해야 합니다.
