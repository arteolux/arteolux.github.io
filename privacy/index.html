## 한국어

8789 Content Studio는 운영자가 자신이 관리하는 소셜 미디어 계정의 콘텐츠를 작성·예약·발행하고 성과를 확인하기 위해 사용하는 로컬 웹앱입니다. 앱 본체는 운영자 PC와 승인된 Tailscale 기기에서 사용합니다. 외부 SNS 플랫폼에 접근하려면 운영자가 해당 플랫폼의 공식 OAuth 동의 화면에서 권한을 승인해야 합니다.

**처리하는 정보.** 연결된 계정의 식별자·사용자명·프로필 정보, OAuth 액세스 및 갱신 토큰, 운영자가 만든 초안·미디어·게시 기록, 플랫폼이 허용하고 운영자가 승인한 범위의 댓글·성과 데이터를 처리할 수 있습니다. 실제로 수집되는 항목은 연결한 플랫폼과 승인한 권한에 따라 다릅니다. 소셜 계정의 비밀번호는 8789에 입력하거나 저장하지 않습니다.

**이용 목적과 외부 전송.** 계정 연결, 본인 계정 확인, 초안 관리, 게시·예약, 댓글·성과 확인에 사용합니다. 게시·조회 요청은 선택한 SNS 플랫폼의 공식 API로 전송됩니다. 운영자가 별도의 AI 생성·음성·이미지 서비스를 설정하고 기능을 사용하는 경우에는 해당 기능에 입력한 문안·미디어가 선택한 외부 서비스로 전송될 수 있습니다. 외부 서비스의 사용 여부와 범위는 운영자의 설정 및 실행에 따릅니다. 연결 계정 데이터와 토큰을 광고 판매 목적으로 제3자에게 판매하지 않습니다.

**보관과 보호.** OAuth 토큰과 앱 Secret은 운영자 PC에서 Windows DPAPI로 암호화해 저장합니다. 초안과 작업 기록은 운영자 PC의 로컬 데이터 디렉터리에 저장합니다. 운영자 PC의 접근 권한 및 백업 관리는 운영자의 책임입니다. 8789의 로그인 없는 개인 운영 모드는 공용 인터넷의 전체 대시보드에 공개하지 않습니다.

**보유 기간과 삭제.** 연결 토큰은 운영자가 계정 연결을 해제할 때 로컬 저장소에서 삭제합니다. 초안·미디어·작업 기록은 별도로 로컬 데이터 파일을 삭제할 때까지 남을 수 있습니다. 계정 연결 해제만으로 이미 SNS 플랫폼에 게시된 콘텐츠가 삭제되지는 않습니다. 자세한 절차는 `/data-deletion`에서 확인할 수 있습니다. 플랫폼 자체에 저장된 정보는 해당 플랫폼의 정책에 따릅니다.

**Meta 게시용 임시 미디어.** 운영자가 Facebook·Instagram 게시 화면에서 로컬 이미지·영상을 선택하면, Meta가 파일을 가져갈 수 있도록 임의의 추측하기 어려운 HTTPS 주소에 임시로 저장합니다. 주소를 아는 사람은 만료 전까지 해당 파일에 접근할 수 있으므로 민감한 파일을 사용하지 마세요. 임시 파일은 48시간 후 접근이 차단되고 이후 파일 정리 시 삭제됩니다. 업로드한 미디어 URL 자체는 게시 기록에 저장하지 않습니다.

**문의.** 개인정보 처리·삭제에 대한 문의는 arteolux@gmail.com으로 보낼 수 있습니다.

**YouTube 및 Google 데이터.** 운영자가 YouTube 채널을 연결할 때 Google OAuth 동의 화면에서 `youtube.upload`와 `youtube.readonly` 권한을 요청합니다. 8789는 연결된 채널의 ID·이름·프로필 사진·영상 수를 조회하고, 운영자가 선택한 영상과 제목·설명·태그·공개 범위를 `videos.insert`로 업로드하며, 업로드한 영상의 상태·기본 통계를 조회할 수 있습니다. 조회한 채널 정보와 업로드 기록은 운영자의 로컬 PC에 보관됩니다. 연결 해제 시 로컬 OAuth 토큰을 삭제합니다. 초안·작업 기록은 별도로 삭제해야 하며, YouTube에 업로드한 영상은 YouTube에서 직접 삭제해야 합니다. Google 계정의 앱 연결 관리 화면에서 접근 권한을 철회할 수도 있습니다. 자세한 절차는 `/data-deletion`에 있습니다. Google의 데이터 처리에는 [Google 개인정보처리방침](https://policies.google.com/privacy)이 적용되며, 8789의 Google API 데이터 사용은 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)를 따릅니다.

**공개 TikTok 초안 업로드 도구.** `/tiktok/`은 TikTok 사용자가 자신의 계정으로 OAuth 연결해 영상을 자신의 TikTok 편집함으로 보내는 공개 기능입니다. 이 기능은 TikTok 계정 ID, 액세스 토큰 및 선택한 영상 파일을 처리합니다. 토큰은 공개 게이트웨이 프로세스 메모리에만 보관되며 재시작 또는 연결 해제 시 제거됩니다. 영상은 서버에 파일로 저장하지 않고 TikTok 업로드 서버에 전달합니다. TikTok 편집함에 전달된 영상의 보관·삭제는 TikTok 정책과 사용자의 TikTok 계정 설정에 따릅니다. 공개 기능은 소유자용 비공개 대시보드 데이터에 접근하지 않습니다.

## English

8789 Content Studio is a self-hosted web application operated by the account owner on their own computer to prepare, schedule, publish, and analyze content for social media accounts they manage. The control dashboard is intended for the operator's local computer and approved Tailscale devices. Each connected social account is authorized through the provider's official OAuth consent screen.

**Data accessed.** Depending on the provider and permissions granted, the app may process account identifiers, usernames and profile details; OAuth access and refresh tokens; drafts, media and publishing records; and replies and insights available through the provider API. Social account passwords are not entered into or stored by 8789.

**Purpose and sharing.** Data is used to connect and identify accounts, manage drafts, publish or schedule content, and review replies and performance. Authorized API requests are sent to the relevant social platform. If the operator configures and uses optional AI, voice, or image services, input text or media for those functions may be sent to the selected service. Tokens and connected-account data are not sold for advertising.

**Storage and security.** App secrets and OAuth tokens are encrypted on the operator's Windows computer with DPAPI. Drafts and work records are stored in local data files. The password-free private dashboard is not intended to be exposed wholesale to the public internet.

**Retention and deletion.** Disconnecting an account deletes its locally stored token. Drafts, media, and work records may remain until the operator deletes the corresponding local files. Disconnecting does not remove content already published to a social platform. See `/data-deletion` for instructions. Provider-held data is governed by that provider's policy.

**Temporary media for Meta publishing.** If the operator selects a local image or video for Facebook or Instagram publishing, the app temporarily hosts it at an unguessable HTTPS URL so Meta can retrieve it. Anyone who obtains the URL can access the file until it expires; do not use sensitive files. Access expires after 48 hours, and the file is removed during a subsequent cleanup. The media URL itself is not stored in the publishing history.

**Contact.** arteolux@gmail.com

**YouTube and Google data.** When the operator connects a YouTube channel, the app requests `youtube.upload` and `youtube.readonly` through Google's OAuth consent screen. It retrieves the connected channel's ID, name, profile image, and video count; uploads a video and the title, description, tags, and visibility explicitly selected by the operator through `videos.insert`; and may retrieve the uploaded video's status and basic statistics. Channel information and upload records are kept locally on the operator's computer. Disconnecting removes the locally stored OAuth token. Drafts and work records require separate local deletion, and videos already uploaded to YouTube must be deleted in YouTube. The operator may also revoke the app's access in Google Account settings. See `/data-deletion` for details. Google's handling of data is governed by the [Google Privacy Policy](https://policies.google.com/privacy). This app's use of Google API data follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy).

**Public TikTok draft uploader.** The `/tiktok/` tool lets TikTok users authorize their own account and send a selected video to their TikTok inbox for further editing. It processes a TikTok account identifier, access token, and the selected video. Tokens are held in public-gateway process memory only and are removed on disconnect or server restart. Videos are streamed to TikTok and are not saved as files by this service. TikTok controls data retained in its own service. The public tool cannot access the operator's private dashboard data.
